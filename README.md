# Portafolio — Andrés Felipe Jiménez Ramírez

## Tecnologías

- HTML5 semántico
- CSS3 (Grid, Flexbox, variables CSS, diseño responsive), dividido en:
  - `main.css` — variables, reset y estilos base
  - `layout.css` — estructura de página, grillas y responsive
  - `components.css` — botones, tarjetas y piezas visuales
  - `animations.css` — transiciones y preferencias de movimiento
- JavaScript (vanilla)
- Google Fonts: Space Grotesk, IBM Plex Sans, IBM Plex Mono

## Funcionalidad

One page que presenta mi perfil como desarrollador y tres proyectos:

- Sección de presentación (hero) con foto y stack de tecnologías.
- Sección de habilidades agrupadas por categoría.
- Sección de proyectos: Database Gaming, EcoMarket y Restaurante Acme, cada uno con
  descripción, tecnologías usadas y enlaces a su repositorio.
- Sección de contacto con correo, GitHub y LinkedIn.
- Navegación fija (sticky) con menú adaptado a móvil.
